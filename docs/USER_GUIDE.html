Santia · Guide utilisateur (Patients)

Tout ce qu’un patient doit savoir pour consulter en ligne.

Ce guide est dédié aux patients. Il explique chaque fonctionnalité : création de compte, demande de consultation, options express, paiement par capture, dossier patient, notifications et messagerie.

Express

Créneaux uniquement aujourd'hui.

Standard

Créneaux à partir de demain.

Paiement

Capture image/PDF, validation manuelle.

1. Créer un compte patient

Inscription

Rendez‑vous sur Créer un compte et remplissez :

  • Nom complet (ex: Mireille Kouam)
  • Email pour les confirmations
  • Téléphone pour le suivi
  • Mot de passe
Connexion

Après inscription, connectez‑vous pour accéder à votre Dossier patient.

Vous pourrez suivre toutes vos consultations et recevoir des notifications.

2. Faire une demande de consultation

1

Choisir la pathologie

Exemples : Perte de poids, Santé sexuelle, Addictions.

2

Décrire le problème

Symptômes, durée, traitements actuels.

3

Renseigner vos infos

Nom, âge, sexe, téléphone, email, ville.

4

Choisir un créneau

Express : aujourd’hui. Standard : dès demain.

5

Paiement & capture

Déposez via Mobile Money et ajoutez la capture (image/PDF).

3. Paiement par capture (image/PDF)

Dépôt

Numéro Mobile Money : 657817198

Après dépôt, téléversez la capture du reçu.

Formats acceptés : JPG, PNG, PDF.
Validation

Votre paiement est validé manuellement par l’administration.

Une fois approuvé, le médecin reçoit un message pour démarrer l’échange.

4. Consultation express vs standard

Express

Créneaux disponibles uniquement aujourd’hui.

Tarif par défaut : 8 000 FCFA.

Standard

Créneaux disponibles à partir de demain.

Tarif par défaut : 5 000 FCFA.

Si aucun créneau express n’est visible, sélectionnez le mode standard.

5. Dossier patient & suivi

Dans “Mon dossier”
  • Statut de la demande
  • Médecin assigné
  • Lien de visio (quand planifié)
  • Capture de paiement (aperçu)
Notifications

Vous recevez des notifications : paiement validé, rendez‑vous planifié, message médecin, etc.

6. Messagerie & visio

Messagerie

Vous pouvez discuter avec votre médecin dans un espace sécurisé.

Un message automatique est déclenché après validation du paiement.

Visio

Un lien de consultation est affiché dans votre dossier.

Connectez‑vous 5 minutes avant l’heure prévue.

Exemple concret

Exemple patient
  • Nom : Mireille Kouam
  • Motif : Perte de poids
  • Type : Express
  • Paiement : Capture PDF ajoutée
Message reçu
Bonjour Mireille, votre paiement est en cours de validation. Dépôt : 657817198 Créneau : Mar 13:00 Lien : https://meet.santia.care/... Merci.

FAQ rapide

Je ne vois pas la capture

Vérifiez que vous avez bien téléversé un fichier sur une nouvelle demande.

Le lien visio n’apparaît pas

Le lien apparaît après validation et planification par l’administration.

Problème de connexion

Déconnectez‑vous puis reconnectez‑vous pour rafraîchir la session.
